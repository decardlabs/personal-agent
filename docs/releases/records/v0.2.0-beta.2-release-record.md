## Summary

Second beta pre-release. Finalizes Phase A hardening with unified LLM context injection, confidence-gated memory write policy and diagnostics observability, expanded replay coverage, and stable local test discovery boundaries.

## What Changed

### Added

- Memory write policy and audit trail (`memoryWritePolicy`) with confidence gating and bypass rules for bookkeeping keys.
- Write-decision diagnostics metrics surfaced in `/diag`, `/status`, and dashboard memory panel.
- Replay scenarios for preference round-trip and confidence-filtered persistent-facts-in-context behavior.
- Deterministic replay support for seeded persistent facts and mock LLM responder modes.
- Dashboard renderer strategy modules for weighting, ordering, and truncation.

### Changed

- Unified LLM context injection through `buildLLMContextBundle` and updated `runTurn`/LLM responder wiring.
- Standardized session history window behavior and edge-case handling.
- Vitest discovery narrowed to `src/**/*.test.ts` and excludes local reference repositories.
- Documentation synchronized across README, engineering plan, roadmap, and changelog.
