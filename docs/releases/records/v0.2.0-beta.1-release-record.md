## Summary

First beta pre-release. Completes the full 6-week engineering plan with a hardened, testable agent loop covering input normalisation, memory, permissions, replay regression, and graceful error handling.

## What Changed

### Added

- `tool_timeout`, `tool_retry`, `tool_error`, `turn_cancelled` event types.
- `turnTimeoutMs` option: turn is cancelled with `turn_cancelled` event when elapsed >= limit.
- `maxToolRetries` option: retries tool on error and emits `tool_retry` per attempt.
- `echoToolRunner` injectable to `TurnOptions` for test isolation.
- Permission expiry check: grants with a past `expires_at` are treated as revoked.
- Graceful `tool_error` event + user-facing error message when all retries exhausted.
- Replay suite expanded to 10 cases (timeout, empty input, whitespace, multi-turn, cold recall).
- `ToolPermissionRepository` unit test suite (4 tests).
- Developer quick-start in README.

### Changed

- `ToolPermissionRepository.hasPermission()` now checks `expires_at`.
- `runTurn` tool execution block now wrapped in try/catch for graceful degradation.
- `package.json` version bumped to `0.2.0-beta.1`.
