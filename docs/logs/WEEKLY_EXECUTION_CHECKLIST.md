# Weekly Execution Checklist

Use this checklist at the beginning and end of every week.

## Weekly Setup (Monday)

- [ ] Review previous week outcomes in DEVLOG and SPRINT_LOG
- [ ] Confirm current milestone target in ROADMAP
- [ ] Define weekly top 3 outcomes
- [ ] Break outcomes into concrete tasks
- [ ] Identify major risks and update RISK_LOG
- [ ] Define validation scope for this week in QA_TEST_LOG

## Daily Routine (Tuesday to Friday)

- [ ] Add daily progress to DEVLOG
- [ ] Update task status against weekly outcomes
- [ ] Record architecture decisions as ADR when needed
- [ ] Capture any scope changes in SPRINT_LOG
- [ ] Log test results and failures in QA_TEST_LOG
- [ ] Update risk status in RISK_LOG if conditions change

## Midweek Checkpoint (Wednesday)

- [ ] Assess progress against top 3 outcomes
- [ ] Re-prioritize remaining tasks if needed
- [ ] Mark blocked items and define mitigation actions
- [ ] Confirm release readiness trajectory

## Week End Review (Friday)

- [ ] Summarize completed work in DEVLOG
- [ ] Update SPRINT_LOG completion metrics
- [ ] Reconcile changelog entries for user-visible changes
- [ ] Confirm VERSION bump need (patch/minor/major)
- [ ] Draft release notes if release candidate is ready
- [ ] Carry over unfinished work to next week plan

## Release Gate (When Applicable)

- [ ] CHANGELOG is up to date
- [ ] VERSION is bumped correctly
- [ ] Release notes draft completed
- [ ] Test and smoke checks logged
- [ ] Risks accepted or mitigated with owner and due date
